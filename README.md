# TO na Net

**Conectando o Tocantins ao Mundo Digital**

Programa estadual de inclusão digital que leva internet gratuita a comunidades indígenas, quilombolas e áreas rurais por meio de tecnologias inovadoras.

## 🌐 Sobre o projeto

O **TO na Net** é um hotsite desenvolvido para apresentar uma iniciativa voltada à democratização do acesso à internet no estado do Tocantins. A proposta é reduzir a desigualdade digital e promover inclusão social, educacional e econômica.

## 🎯 Objetivo

Levar conectividade a regiões com acesso limitado ou inexistente à internet, utilizando soluções tecnológicas eficientes e acessíveis.

## 🚀 Tecnologias utilizadas

- Next.js
- React
- HTML5
- CSS3
- JavaScript
